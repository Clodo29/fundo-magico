# Fundo Mágico

**Autor:** Clodo29

> Projeto front-end simples que implementa um efeito/tema chamado "Fundo Mágico".

## Descrição

Pequeno site estático feito com HTML, CSS e JavaScript. Ideal para demonstrações e estudos sobre animações de fundo, responsividade e organização básica de projetos front-end.

## Recursos

- Layout responsivo
- Animações/efeitos no fundo
- Estrutura simples e fácil de estender

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- `index.html` — página principal
- `src/css/` — arquivos de estilo (`estilos.css`, `reset.css`, `responsivo.css`)
- `src/js/index.js` — scripts JavaScript
- `src/images/` — imagens do projeto

## Como usar

1. Clone o repositório:

```
git clone https://github.com/Clodo29/szpc-fundo-magico.git
```

2. Abra `index.html` no navegador (duplo clique ou via servidor local).

Dica: para testar com recarregamento e sem problemas de CORS, use um servidor simples, por exemplo:

```
# Python 3
python -m http.server 8000

# ou usando Live Server (VS Code)
```

## Desenvolvimento

- Faça mudanças em `src/css/` e `src/js/`.
- Teste abrindo `index.html` ou via servidor local.
